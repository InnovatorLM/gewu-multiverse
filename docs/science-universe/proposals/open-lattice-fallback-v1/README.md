# Open two-sublattice soft-mode fallback

This package is an independently authored, CC0-compatible model for a finite-periodic lattice-dynamics task. It avoids redistribution of the unresolved Ti EAM files. The model is a two-sublattice cubic crystal with a finite-range harmonic force law and a stabilizing quartic energy term. The public task supplies paired force responses and an independent energy interface; the solver must reconstruct the mass-weighted finite-periodic spectrum and identify the lowest non-Gamma grid mode.

This is a model-material calculation, not a claim about experimental titanium. All parameters and equations are included in `model.py`; no external assets are required.
