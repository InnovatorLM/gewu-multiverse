# 电池降阶模型的一手文献核查

## 原文实际支持的结论

- 引言、推导和末尾的模型适用条件表，说明 SPM/SPMe 简化依赖明确的时间尺度和导电性极限，不能无条件代替 DFN。论文给出参数组合及渐近误差阶估计；这不是任意电池参数、任意场变量的严格有限误差上界。
- “Voltage comparison”部分确实比较 SPM、SPMe 与 DFN 在多个倍率下的恒流放电。其特定参数下，低倍率匹配较好，较高倍率和放电末端可出现更大偏差。文中把末端部分偏差联系到 OCP 的强非线性及被省略的高阶项。
- 输出电压的点值形式与电极平均形式是论文的重要推导问题。这支持认真核实变量定义，但不能直接等同于当前候选所说的局部负极电位与平均值的安全判定分歧。
- 论文讨论 DFN 的计算代价及变电流情况下的收敛问题。求解器失败不能当作物理约束违约；论文耗时也不能作为当前版本或 ACS 2c4g 的运行时间保证。

## 不支持直接外推的事项

该论文的放电比较不证明 Chen2020 参数在本项目快充工况下有效，不证明某条快充曲线一定出现局部违约，也不证明电位非负就能保证真实电池没有镀锂。示例中的倍率、误差数值和时间不能移植为本题评分阈值。原文的渐近结论也不免除当前软件版本、参数、网格、容差和事件的独立验证。

因此，模型适用边界是有文献依据的研究问题；本候选是否具有区别于已有控制题/官方示例的科学内容，仍取决于离线计算与独立领域审核。论文存在本身不证明题目新颖或困难。
