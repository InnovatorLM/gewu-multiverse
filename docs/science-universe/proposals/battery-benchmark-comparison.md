# 电池候选方向：公开题面比较

结论：尚不能接受该方向的原创性或科学价值。这里只完成固定版本公开题面的人工内容比较，不替代评价角色的 semantic 审查，也没有运行答题模型或形成正式题目。

候选研究问题是：降阶电池模型设计的充电曲线，能否在空间分辨 DFN 模型中保持声明的局部电位裕量；若不能，提供满足共同公开性能合同的替代曲线。全阶计算仍是模型结果，不是实际电池安全证明。

比较语料包含 Terminal-Bench-Science 72 题及 Terminal-Bench-4.0 66 题。相邻 JSON 保存所读题面的完整 commit、路径、Git blob 和内容 SHA256；已逐项重新计算内容哈希。

| 现有题目 | 实质重叠 | 对候选的要求 |
| --- | --- | --- |
| Science `reactor-safety-control` | 在故障、参数失配和噪声下设计控制，满足硬安全约束及性能目标，由可信模拟器重算。结构重叠强。 | 仅更换为电池或增加参数场景不够；若核心仍是同构黑箱约束优化，应拒绝。 |
| TB4 `biped-contact-dynamics` | 提交轨迹，由完整物理模型核查可行性与约束，允许不同生成方法。 | 数据交付与可信重算本身不构成新科学贡献；区别需来自可验证的模型适用边界。 |
| TB4 `ks-solver-cpp` | 数值 PDE、固定误差标准与计算资源限制。 | 不能以 PDE 复杂度或求解耗时单独证明科学价值或难度。 |
| TB4 `lake-temp-glm` | 局部剖面与整体误差的不同验收口径。 | 局部与平均电位区别须实际出现并有科学意义，不能只增加一个评分维度。 |

PyBaMM 固定版本的官方 `lithium-plating.ipynb` 已涉及 DFN、低温快充、不同倍率及负极相关量。普通“运行几条充电曲线并比较”存在示例复用风险。没有搜索到同名优化文件不能证明不存在现成解。

下一项有用证据是离线数值筛查：固定模型、参数和变量定义，比较 SPM/SPMe/DFN 以及简单恒流策略；明确记录电压事件提前终止。只有出现具有实际意义且数值收敛的模型判定差异，才考虑进一步形成问题。若简单策略已达全部目标，不通过事后收紧阈值制造难度。当前没有可行替代见证、正式阈值、收敛结果或指定模型正确率证据。
