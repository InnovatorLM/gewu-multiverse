# 模型请求增量归档

每个会话首个model_request.body保存完整JSON；后续请求在模型选项不变且非system历史保持前缀一致时，保存gewu.request-delta.v1。字段包括前一请求消息数量、替换后的system消息、新增消息及请求选项。摘要或历史改变后重新写完整检查点。

所有独立工具调用、工具结果和模型回复仍保留，未裁剪旧轨迹。增量记录是脱敏后的JSON语义重放，不承诺保留HTTP JSON原始空白或键顺序。摘要模型调用的请求、回复与用量也写入相同归档；当前仍需真实长会话验收。

重建方式：运行 deploy/science/trajectory_requests.py，传入完整transcript.jsonl与 --output 指定工作区内新文件。输出为逐请求JSONL，模式0600；若读取或重放失败，删除不完整输出。输入必须从首个完整检查点开始，不能只对末尾截断片段重放。生产网页目前显示原始增量事件，完整重放由该CLI提供。

测试覆盖system变化、工具调用及结果、Unicode、摘要后的完整检查点、缺失基线和配置变化。在线长会话与网页重放仍需验收。
